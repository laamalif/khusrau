# Module guide

| Module | Role |
|---|---|
| `khusrau.py` | Unified command-line interface |
| `vertex.py` | Guarded Vertex AI model access |
| `ocr_page.py`, `ocr_batch.py` | Verse, prose, and dictionary OCR artifacts |
| `ganjoor.py`, `verify_ganjoor.py` | Ganjoor retrieval, indexing, and validation |
| `rekhta*.py` | Rekhta verse and prose extraction |
| `corpus.py` | Reference-divan loading and radīf grouping |
| `selftest_align.py` | Hemistich retrieval engine and evaluation |
| `manufacture.py` | Verse sequence scoring and tier assignment |
| `align_prose.py`, `score_real.py` | Continuous prose alignment and error metrics |
| `urdu_norm.py`, `norm_profiles.py` | Retrieval and apparatus normalization |
| `dictionary_extract.py` | Image-aware structured dictionary extraction |
| `dictionary_local.py` | Local-only conservative dictionary extraction |
| `dataset_export.py` | Hashed manifests and validated page-pair exports |
| `test_integrity.py`, `test_norm.py` | Cross-module and normalization regression tests |
